# Web site

A static site (no build step): open `index.html` through any web server, e.g. `python -m http.server -d site`.

- `js/gamesim.js` game-exact simulator (belts, splitters, undergrounds, arms, machines, storage, extractors),
  a port of the Python reference sim. Same float32 maths and the same tick order as the game.
- `js/blueprint.js` reading blueprints (json rows, solver text grids, ids through Human-Crow's blueprint service),
  open belt starts and ends as inputs and outputs, guessing input items from the machines downstream.
- `js/view.js` the map: buildings, belts, flow lines sized by throughput, moving items, per-tile numbers.
- `js/app.js` the simulator page: game speed, per-minute rates, "run until settled" with the long-run average.
- `js/designer.js` solver gallery and the live view of a running `python -m bmsolver ... --live`.
- `js/gamedata.js` game tables, generated by `tools/make_gamedata.py`.
- `tools/run.mjs` headless run (`node site/tools/run.mjs layout.json ticks every`) printing state digests, used to
  check the JavaScript sim tick for tick against the Python one.

Traced and modelled: the belt quadtree for arm lookups (33 per cell, fresh on load, at the build's world
position), the full arm filter item-id table, power plants (fuel load, timer, radius box, largest boost wins),
open belt ends that stop unless marked as outputs, and the production tab's 2-minute float32 readout.

Settings: number of researched belt speed techs (0 to 12; they form one prerequisite chain, so 12 gives exactly
480/min), underground range 5/6/7, the splitter start output, world position.

Traced and on: roundf (halves away from zero) for lengths and arm projections, arms taking from extractor stock,
building boxes by size (1x1 +-0.4998 ...) for power plant range overlap, and the tile hash-map order for piece
creation (robin_hood 3.11 maps filled in blueprint row order, checked slot for slot against the real robin_hood.h).

Also traced: labs and gold vaults take any item, crafters one craft's worth, storage 250 with no tier factor (same
on iOS Gen 2), the teleporter is a plain crafter, gem trees. Not modelled: iOS fused multiply-adds (expected to be
tiny).
