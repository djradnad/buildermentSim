# Web site

A static site (no build step): open `index.html` through any web server, e.g. `python -m http.server -d site`.

- `js/gamesim.js` game-exact simulator (belts, splitters, undergrounds, arms, machines, storage, extractors),
  a port of the Python reference sim. Same float32 maths and the same tick order as the game.
- `js/blueprint.js` reading blueprints (json rows, solver text grids, ids through Human-Crow's blueprint service),
  open belt starts and ends as inputs and outputs, guessing input items from the machines downstream.
- `js/view.js` the map: buildings, belts, flow lines sized by throughput, moving items, per-tile numbers.
- `js/app.js` the simulator page: game speed, per-minute rates, "run until settled" with the long-run average.
- `js/designer.js` solver gallery and the live view of a running `python -m bmsolver ... --live`.
- `js/gamedata.js` game tables, generated by `tools/make_gamedata.py`.
- `tools/run.mjs` headless run (`node site/tools/run.mjs layout.json ticks every`) printing state digests, used to
  check the JavaScript sim tick for tick against the Python one.

Not traced yet: what labs and power plants accept (here they take every item), storage tier limits, the arm
filter item ids other than Wood Plank (1001) and Nuclear Fuel Cell (1053), the belt quadtree for arm lookups
(arms use the first segment in creation order, as on a freshly loaded world in most layouts).
